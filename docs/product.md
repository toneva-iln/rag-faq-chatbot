# Product FAQ

## Supported platforms

Our app runs on web (Chrome, Safari, Firefox, Edge), iOS 16+, and Android 12+.
There is no desktop app, but the web app works offline for viewing.

## Plan limits

- Free: 3 projects, 1 GB storage, community support
- Pro ($12/month): unlimited projects, 50 GB storage, email support
- Team ($29/user/month): everything in Pro plus shared workspaces, SSO,
  and priority support with 4-hour response time

## Exporting your data

You can export all your data as JSON or CSV from Settings > Data > Export.
Exports are generated within a few minutes and emailed as a download link
that expires in 48 hours.

## API access

API access is available on Pro and Team plans. Generate an API key under
Settings > Developer. Rate limit is 100 requests/minute on Pro and
1,000 requests/minute on Team.
